# EXP-017 学习说明：精度通过，性能未采用

当时推荐基线是 **EXP-016**。它恢复后12/12 Pass，复测13.5008µs，历史公开第13名、47.11分。源码没有变化，复测更低不能称为新算法收益；这些是当时记录，不代表当前022或实时榜单。

EXP-017尝试复用Sigmoid与解码的临时缓冲，并采用FP16每块1024、FP32每块768。它12/12精度通过，但均值14.4683µs，比原EXP-016慢6.28%，所有测试点退步，因此未采用。

## 值得理解的正确性设计

1. Div消费完sigB分母后，六个Gather把六条字段向量写入sigB。
2. 六个Gather全部读完sigA的Sigmoid结果后，sigA起始部分才作为宽高平方临时量。
3. 宽高临时量被消费后，FP16输出Gather使用sigA暂存交错输出，再Cast到独立输出队列。
4. 五条priors系数独立放在fieldBuf，跨batch保留；搬入和写回仍使用原来的双缓冲队列。

这些复用在当前12个设备测试里保持了精度；但保持正确和减少分配，并不自动证明速度更好。

## 这次不能下的结论

不能把退步单独归因于某条指令、缓存冲突或复用本身。布局和tile同时改变，尚无生成指令与profiling证据。也不能把此次组合慢了扩展为“所有复用或大tile都无效”。

可以确认的是：此次完整组合没有获得收益，所以保留原基线。恢复原源码的相邻复测也显著快于17，但仍不能替代多次受控A/B。
