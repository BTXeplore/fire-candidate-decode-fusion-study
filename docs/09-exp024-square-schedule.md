# EXP-024：用已有临时槽分开宽高平方

2026-10-22。本轮只新增一个候选，以 EXP-022 为独立基线；不叠加未采用的 EXP-023 字段间距改动。本轮三项真实测量与归档均已完成，未采用候选，平台及推荐源码保持原EXP-022。

## 改动及其含义

对照 [EXP-022 的 ComputeTile](../history/EXP-022/op_kernel/fire_candidate_decode_fusion.cpp) 与 [EXP-024 的同一函数](../history/EXP-024/op_kernel/fire_candidate_decode_fusion.cpp)，唯一运算变动如下，所有调用仍使用有效长度 count：

|顺序|EXP-022|EXP-024|
|---|---|---|
|1|t0 = sw × sw|t0 = sw × sw|
|2|sw = t0 × aw|t2 = sh × sh|
|3|t0 = sh × sh|sw = t0 × aw|
|4|sh = t0 × ah|sh = t2 × ah|

原版两条链共享 t0：宽度运算读完该槽之后，高度平方才能覆盖它。这条先读后写关系称为 WAR（Write After Read），它由临时地址复用产生，并非宽高数学上相互依赖。新代码将高度平方放入已有 t2，解除这条跨链假依赖；每条链内部“平方完成后再乘系数”的真实数据依赖仍然存在。

四次 Mul 的数量不变；每个输出元素仍分别执行 `(sw*sw)*aw`、`(sh*sh)*ah`，操作数、FP32 类型和乘法树不变，没有重新结合、增加 FMA 或改变最终 Cast。其余源码、Host、TILE_N=704、分核、索引、队列、输出布局均保持基线。

## 生命周期与尾块

fieldBuf 已分配 14×T 个 FP32 元素；t0 位于第11槽，t2 位于第13槽，各占 T 个元素。LoadPriors 使用第0槽作为暂存，将持久系数保存在第6～10、12槽，不使用第13槽。ComputeTile 的输入与结果占第0～5槽，因此新增 t2 写入与这些存活数据不重叠。

每次 batch 计算都会先写高度平方，再读取 t2；后续 batch 和下一 Tile 可以覆盖旧临时值。count≤T，尾块仍只写、读 count 个元素，Gather 只组织五个有效结果字段。显式 UB 仍为 FP16 输入168960B、FP32 输入185856B；这不包括编译器可能使用的隐含资源。

## 什么已经验证，什么仍是问题

候选 kernel 为12243B，SHA256：`6752e17c1758f6236e0aaf0d0963fb9768f47d7d8ac95a72ef97434da2aeb926`。本地符号模型检查 count=1..704、连续8次 batch 复用，共5632个状态：乘法树、临时槽互斥、先写后读、持久系数及其余源码一致性均通过。

这不是设备执行或浮点指令仿真。**性能假设**是独立临时槽可能给编译排程更多余地；源码并不能证明已生成重叠指令，也不能保证 Vector 单元执行得更快。计算量和调用数都没有减少，不能按“少了一条依赖”直接预测时延。

实际按原22前控→24→原22后控/恢复完成。每次有效提交都取得唯一编号，实际服务器七份源码逐份全文核对一致，仅规范CRLF/LF。没有待完成或未知评测。

## 为什么没有直接换 Reciprocal

曾检查以倒数替换 Div 的方向，但没有创建或提测该候选。本地旧头文件取自 master，不能证明正式 CANN 9.0.0 支持。检索到的[旧版官方8.0.RC2文档](https://www.hiascend.com/doc_center/source/zh/canncommercial/80RC2/apiref/opdevgapi/CANN%208.0.RC2%20%E7%AE%97%E5%AD%90%E5%BC%80%E5%8F%91%E6%8E%A5%E5%8F%A3%2001.pdf)有倒数精度警告；900beta2路径的检索标题与正文有不一致，直接读取也曾超时。正式9.0.0的完整接口与精度证据仍缺，故未把直接替换带入本轮候选；不据旧资料宣称正式9.0.0不支持或必然失败。

数学上，Sigmoid 误差会经坐标系数及宽高平方传播；有限输入也可能使中间 Exp 溢出。仅有相同实数公式不够证明可替换。本轮学习的重点因此是：先区分真实依赖与存储假依赖，做一个保持算术路径的最小实验，再让设备结果决定去留。

同源码对照本身波动，12个测试点也不能当作同一负载的12次受控重复。因此不将不足1%的单次均值变化归因于调度改动，更不声称已观察到Vector重叠。新算力到位后，值得补的是同机交替重复、编译指令与真实流水线时间线。
